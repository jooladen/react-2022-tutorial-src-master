**화면** (겉모습은 03과 같음. 클릭했을 때가 다름)
```
WEB 클릭        → 알림창 "Header"   (페이지 새로고침 없음)
html 클릭       → 알림창 "1"
css 클릭        → 알림창 "2"
```

**꽂을 한 문장**: **자식은 부모 함수를 props로 받아서 부른다.** props는 부모 → 자식(값 내려주기), 이벤트는 자식 → 부모(신호 올려주기).

- 🟢 **초딩용**: 엄마가 아이에게 무전기(함수)를 쥐여 준다. 아이는 무슨 일이 생기면 무전기 버튼만 누른다. 그다음 무엇을 할지는 엄마가 정한다.
- 🔵 **개발자용**: 콜백 패턴. 부모가 `onChangeMode={함수}`로 함수를 내려주면 자식은 이벤트가 났을 때 `props.onChangeMode(값)`을 호출한다. 자식은 부모가 무엇을 할지 모르기 때문에 재사용성이 높아진다.

## 📥 시작 코드 (= 03 정답 + TODO)

```js
import './App.css';

function Header(props){
  // TODO 1: 아래 a 태그에 onClick 달기
  //   - event.preventDefault() 로 페이지 이동 막기
  //   - props.onChangeMode() 호출
  return <header>
    <h1><a href="/">{props.title}</a></h1>
  </header>
}
function Nav(props){
  const lis = []
  for(let i=0; i<props.topics.length; i++){
    let t = props.topics[i];
    // TODO 2: a 태그에 id={t.id} 속성과 onClick 달기
    //   - event.preventDefault()
    //   - props.onChangeMode(Number(event.target.id))
    lis.push(<li key={t.id}><a href={'/read/'+t.id}>{t.title}</a></li>)
  }
  return <nav>
    <ol>
      {lis}
    </ol>
  </nav>
}
function Article(props){
  return <article>
    <h2>{props.title}</h2>
    {props.body}
  </article>
}
function App() {
  const topics = [
    {id:1, title:'html', body:'html is ...'},
    {id:2, title:'css', body:'css is ...'},
    {id:3, title:'javascript', body:'javascript is ...'}
  ]
  return (
    <div>
      {/* TODO 3: Header에 onChangeMode={()=>{ alert('Header'); }} 넘기기 */}
      <Header title="WEB"></Header>
      {/* TODO 4: Nav에 onChangeMode={(id)=>{ alert(id); }} 넘기기 */}
      <Nav topics={topics}></Nav>
      <Article title="Welcome" body="Hello, WEB"></Article>

export default App;
```

## ✍️ 할 일

1. `Header`의 a 태그에 `onClick`을 달아 `props.onChangeMode()`를 부른다.
2. `Nav`의 a 태그에 `id`와 `onClick`을 달아 `props.onChangeMode(Number(event.target.id))`를 부른다.
3. `App`에서 두 컴포넌트에 `onChangeMode` 함수를 넘긴다.
4. **실험 A**: `event.preventDefault()`를 지우고 html을 클릭해 본다 → 주소창이 `/read/1`로 바뀌고 페이지가 새로고침되는 걸 확인한다. 확인했으면 다시 넣는다.
5. **실험 B**: `Number(...)`를 빼고 `alert(typeof id)`로 바꿔 본다 → `string`이 뜨는 걸 확인한다. 확인했으면 원래대로 되돌린다.

<details>
<summary>💡 힌트 1 — 화살표 함수 모양</summary>

```js
<a href="/" onClick={(event)=>{
  event.preventDefault();
  props.onChangeMode();
}}>
```
`onClick={...}` 안에는 **함수 자체**를 넣는다. `onClick={props.onChangeMode()}`처럼 쓰면 클릭할 때가 아니라 **화면을 그리는 순간** 함수가 실행된다.
</details>

## 🔧 실무 버전

`id`를 DOM 속성에 심었다가 `event.target.id`로 다시 꺼내는 대신, 클로저로 바로 넘긴다: `onClick={e => { e.preventDefault(); props.onChangeMode(t.id); }}`. 이렇게 하면 문자열→숫자 변환도 필요 없다. 강의는 "event 객체에서 정보를 꺼낼 수 있다"를 보여주려고 이 방식을 썼다.
