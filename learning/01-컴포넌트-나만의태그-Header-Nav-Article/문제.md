## 🎯 이 단계가 끝나면

**화면** (지금과 똑같아 보임 — 겉모습은 그대로, 코드 구조만 바뀜)

**꽂을 한 문장**: **컴포넌트 = 이름 붙인 HTML 묶음.** `<header>...</header>` 덩어리에 `Header`라는 이름을 붙이면 `<Header></Header>` 한 줄로 쓸 수 있다.

- 🟢 **초딩용**: 자주 쓰는 레고 조립 덩어리에 이름표를 붙여 두는 것. 다음엔 "지붕 하나 줘" 하면 끝.
- 🔵 **개발자용**: JSX를 반환하는 함수. 이름은 **반드시 대문자로 시작**해야 한다(소문자면 HTML 태그로 해석).

### 🎬 시범: TODO 1 (Header) — 이건 따라 치세요

"덩어리를 옮긴다" = **App 안의 `<header>...</header>` 부분을 잘라내서, 새 함수의 return 뒤에 붙인다.**

**① 함수 껍데기를 만든다** — `// TODO 1` 줄 아래에 친다
```js
function Header(){
  return <header>

  </header>
}
```

**② App 안에서 `<header>` 안쪽 내용을 잘라내서(`Ctrl+X`) 껍데기 안에 붙인다(`Ctrl+V`)**
```js
function Header(){
  return <header>
    <h1><a href="/">WEB</a></h1>
  </header>
}
```
↑ 가운데 `<h1>...</h1>` 줄이 App에서 잘라 온 줄이다. (JSX 안에서는 `//` 주석을 못 쓴다. 쓰면 화면에 글자로 찍힌다. JSX 안 주석은 `{/* */}`)

**③ App에 남은 빈 `<header></header>` 자리를 `<Header></Header>`로 바꾼다** (대문자 H!)
```js
function App() {
  return (
    <div>
      <Header></Header>               {/* ← 원래 <header>...</header> 3줄이 있던 자리 */}
      <nav>
      ...
```

**④ 저장(`Ctrl+S`) → 브라우저를 본다**
화면이 **전과 똑같으면 성공**. 겉모습은 그대로인데 코드가 `Header`라는 부품으로 나뉜 것이다.
화면이 하얗게 되면 → 터미널 **마지막 줄**부터 읽는다 (로그 읽는 법 복습). 아래 💡 힌트 2도 본다.

### ✋ 이제 직접: TODO 2 (Nav), TODO 3 (Article)

시범과 **똑같은 ①②③④**를 `<nav>`와 `<article>`에 반복한다.

## 📥 시작 코드 (`src/App.js`에 통째로 붙여 넣기)

```js
import './App.css';

// TODO 1: Header 컴포넌트를 만드세요 (아래 App의 <header> 덩어리를 옮김)

// TODO 2: Nav 컴포넌트를 만드세요 (<nav> 덩어리)

// TODO 3: Article 컴포넌트를 만드세요 (<article> 덩어리)

function App() {
  return (
    <div>
      <header>
        <h1><a href="/">WEB</a></h1>
      </header>
      <nav>
        <ol>
          <li><a href="/read/1">html</a></li>
          <li><a href="/read/2">css</a></li>
          <li><a href="/read/3">javascript</a></li>
        </ol>
      </nav>
      <article>
        <h2>Welcome</h2>
        Hello, WEB
      </article>
      {/* TODO 4: 위 세 덩어리를 지우고 <Header></Header> <Nav></Nav> <Article></Article> 로 바꾸세요 */}
    </div>
  );
}

export default App;
```

> 참고: 원본 1번째 줄의 `import logo ...`는 일부러 뺐습니다. 안 쓰는 import라서 경고만 띄웁니다. (`npm-start-경고4종-...md` 참고)

## ✍️ 할 일

1. `function Header()`를 만들고 `<header>` 덩어리를 `return`한다.
2. `Nav`, `Article`도 같은 방식으로 만든다.
3. `App`의 `return`에서 덩어리 3개를 `<Header></Header>`, `<Nav></Nav>`, `<Article></Article>`로 바꾼다.
4. 화면이 **바꾸기 전과 똑같은지** 확인한다.

<details>
<summary>답 보기</summary>

2. 내용이 컴포넌트 안에 고정돼 있어서 제목만 다른 컴포넌트를 또 만들어야 한다. 바깥에서 값을 넣어 줄 방법이 필요하고, 그게 props다.
