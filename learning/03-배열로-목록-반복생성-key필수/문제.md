# 03. 배열로 목록 반복 생성 — key 필수

> MECE: **A2 props** (배열을 props로 내려서 화면을 만든다)

## 🎯 이 단계가 끝나면

**화면** (겉모습은 02와 같음)
```
WEB
 1. html
 2. css
 3. javascript
Welcome
Hello, WEB
```

**확인 방법**: `topics` 배열에 `{id:4, title:'react', body:'react is ...'}`를 추가하면 → **Nav 코드를 한 줄도 안 고쳐도** "4. react"가 화면에 생긴다.

**꽂을 한 문장**: **데이터가 화면을 만든다.** `<li>`를 손으로 3번 쓰는 대신, 데이터(배열)를 주면 컴포넌트가 개수만큼 그린다.

- 🟢 **초딩용**: 반 친구 이름표를 하나하나 손으로 쓰지 않고, 명단을 프린터에 넣으면 인원수만큼 뽑혀 나오는 것.
- 🔵 **개발자용**: JSX 배열을 `{}` 안에 넣으면 React가 펼쳐서 렌더링한다. 반복으로 만든 요소에는 **고유한 `key`**를 줘야 한다. React가 어떤 항목이 바뀌었는지 추적하는 이름표다.

## ✍️ 할 일

1. `App` 안에 `topics` 배열을 만든다.
2. `<Nav topics={topics}>`로 넘긴다. ⚠️ 문자열이 아니라 **변수**라서 따옴표가 아니라 `{}`를 쓴다.
3. `Nav` 안에서 `for` 문으로 `lis` 배열을 채우고 `{lis}`로 출력한다.
4. `key`를 **빼고** 실행해서 브라우저 콘솔(F12)에 뜨는 경고를 직접 본다. 그다음 `key`를 넣고 경고가 사라지는지 확인한다.
5. 🎯 확인 방법대로 4번째 글을 넣어 보고, 확인이 끝나면 다시 3개로 되돌린다.

## 🔧 실무 버전

`for` + `push` 대신 `map` 한 줄을 쓴다.
```js
<ol>{props.topics.map(t => <li key={t.id}><a href={'/read/'+t.id}>{t.title}</a></li>)}</ol>
```
강의는 `map`을 몰라도 원리(JSX 배열 → 펼쳐서 렌더링)를 이해하도록 `for` 문을 쓴다.

## 🧠 셀프체크 (코드 보지 말고 말로)

1. `<Nav topics="topics">`(따옴표)와 `<Nav topics={topics}>`(중괄호)는 무엇이 다른가?
2. `key`가 없으면 화면은 정상인데 왜 React는 경고를 띄우는가?
3. 지금 `topics`는 그냥 `const` 배열이다. 나중에 "글 추가" 버튼으로 이 배열에 push하면 화면이 바뀔까? → **05·07번의 복선**

<details>
<summary>답 보기</summary>

1. 따옴표는 `"topics"`라는 **글자**를 넘긴다. 중괄호는 `topics` **변수의 값(배열)**을 넘긴다.
2. 목록이 바뀔 때(추가/삭제/순서 변경) React가 어떤 `<li>`가 어떤 데이터인지 구별하려면 이름표가 필요하다. 처음 그릴 때는 문제가 없어 보여도, 바뀔 때 엉뚱한 항목을 재사용해서 버그가 생길 수 있다.
3. 안 바뀐다. 일반 변수는 값이 바뀌어도 React가 다시 그려야 한다는 걸 모른다. 그래서 state(05번)가 필요하고, 배열은 복사해서 바꿔야 한다(07번).
</details>
