# 05. state — mode로 화면 전환

> MECE: **A4 state**

## 🎯 이 단계가 끝나면

**화면**
```
처음           → Welcome / Hello, WEB
html 클릭      → Read / Hello, Read      (alert 없이 본문이 바뀜)
WEB 클릭       → Welcome / Hello, WEB    (다시 돌아옴)
```
※ 아직 html, css 중 무엇을 눌러도 똑같이 "Read"가 나온다. 정상이다 (06번에서 해결).

**꽂을 한 문장**: **일반 변수로는 화면이 안 바뀐다.** state를 바꾸는 함수(`setMode`)로 바꿔야 React가 컴포넌트를 다시 실행해서 화면을 새로 그린다.

- 🟢 **초딩용**: 칠판(화면)은 선생님(React)만 다시 쓸 수 있다. 내 공책(일반 변수)에 아무리 고쳐 적어도 칠판은 안 바뀐다. 선생님에게 "바꿔 주세요" 하고 말해야(setMode) 칠판이 다시 써진다.
- 🔵 **개발자용**: `useState(초기값)`는 `[값, setter]`를 반환한다. setter를 호출하면 React가 해당 컴포넌트 함수를 **다시 실행(re-render)**하고, 그때 `useState`는 초기값이 아니라 **바뀐 값**을 돌려준다.

function Header(props){

function Nav(props){
  const lis = []
  for(let i=0; i<props.topics.length; i++){
    let t = props.topics[i];
    lis.push(<li key={t.id}>
      <a id={t.id} href={'/read/'+t.id} onClick={event=>{
        event.preventDefault();
        props.onChangeMode(Number(event.target.id));
      }}>{t.title}</a>
    </li>)
  }
  return <nav>
    <ol>
      {lis}
    </ol>
  </nav>
}
function Article(props){
  return <article>

    {props.body}
  </article>
}
function App() {

  //   - READ    → <Article title="Read" body="Hello, Read">

## ✍️ 할 일

1. **실험 (일부러 실패하기)**: `let mode = 'WELCOME';`과 if 문으로 `content`를 고르고, 이벤트 함수 안에서 `mode = 'READ';`로 바꾼다. 그리고 html을 클릭한다 → **화면이 안 바뀌는 것**을 확인한다. 이 실패를 직접 겪는 게 이 단계의 핵심이다.
2. `useState`를 import하고 `const [mode, setMode] = useState('WELCOME');`로 바꾼다.
3. 이벤트 함수에서 `mode = ...` 대신 `setMode('READ')`, `setMode('WELCOME')`을 부른다.
4. html 클릭 → Read, WEB 클릭 → Welcome으로 바뀌는지 확인한다.

## 🔧 실무 버전

mode 같은 "화면 상태"는 실무에서 대개 **URL(라우터)**로 관리한다 (`react-router`의 `/read/1`). 그러면 새로고침이나 뒤로 가기를 해도 화면이 유지된다. 강의는 라우터 없이 state의 원리만 보여준다.
