# 02. props — 부모가 자식에게 제목 내려주기

> MECE: **A2 props**

## 🎯 이 단계가 끝나면

**화면**
```
REACT                ← 새로 추가한 Header (제목만 다름)
WEB
 1. html
 2. css
 3. javascript
Welcome
Hello, WEB
```

**꽂을 한 문장**: **같은 컴포넌트에 다른 값을 넣는다.** `<Header title="WEB">`처럼 HTML 속성 쓰듯 값을 넘기면, 컴포넌트는 `props.title`로 받는다.

- 🟢 **초딩용**: 똑같은 붕어빵 틀(컴포넌트)에 팥을 넣으면 팥붕, 슈크림을 넣으면 슈붕. 넣는 재료가 props.
- 🔵 **개발자용**: props는 컴포넌트 함수의 **첫 번째 매개변수(객체)**다. `<Header title="WEB">` → `Header({title: "WEB"})` 호출과 같다. 방향은 **부모 → 자식, 한 방향**이다.

## ✍️ 할 일

1. `Header`가 `props`를 받아서 `props.title`을 화면에 찍게 한다.
2. `Article`도 `props.title`, `props.body`를 쓰게 한다.
3. `App`에서 값을 넘긴다. Header를 하나 더 만들어 `REACT`도 띄운다.
4. 다 되면 `REACT` Header는 **지운다** (확인용이었음. 03번 시작 코드에는 없다).

<details>
<summary>💡 힌트 1 — JSX 안에서 값 꺼내기</summary>

JSX 안에서 자바스크립트 값을 쓰려면 중괄호 `{}`로 감싼다.
```js
<h1>{props.title}</h1>
```
그냥 `<h1>props.title</h1>`이라고 쓰면 "props.title"이라는 **글자**가 그대로 찍힌다.

## 🔧 실무 버전

구조 분해로 받는 경우가 많다: `function Header({ title }) { ... {title} ... }`. 강의는 "props가 객체"라는 걸 보여주려고 `props.title` 형태를 유지한다.

## 🧠 셀프체크 (코드 보지 말고 말로)

1. `<Header title="WEB">`에서 `title`은 Header 함수 안에서 어떤 모양으로 도착하는가?
2. 자식(`Header`) 안에서 `props.title = "XXX"`로 바꾸면 어떻게 될까? 바꿔도 될까?

<details>
<summary>답 보기</summary>

1. 함수의 첫 번째 매개변수 객체의 속성으로 도착한다. `props = { title: "WEB" }`
2. 안 된다. props는 **읽기 전용**이다. 값은 부모가 정하고, 자식은 받아서 쓰기만 한다. 자식이 바꾸고 싶은 상황(예: 수정 화면)은 09번 Update2에서 state로 해결한다.
