# 08. Update ① — 수정 화면 진입 + contextControl

> MECE: **B3 Update** (전반부)

## 🎯 이 단계가 끝나면

**화면**
```
처음(Welcome)    → 아래 메뉴: • Create                  (Update 없음)
html 클릭        → 아래 메뉴: • Create  • Update        (Update 등장)
Update 클릭      → Update 폼, title 칸에 "html", body 칸에 "html is ..." 채워져 있음
폼에 글자 입력   → ❌ 안 쳐진다  ← 이 단계의 의도된 결말
Update 버튼      → F12 콘솔에 "html html is ..." 출력
```

**꽂을 한 문장**: **상황별로 메뉴가 달라진다.** 그리고 **props로 value를 고정하면 입력이 안 된다.** 이 문제를 09번에서 푼다.

- 🟢 **초딩용**: 메뉴판이 손님 상황에 따라 바뀐다. 음식을 고른 뒤에야 "변경하기" 버튼이 생긴다. 그런데 변경 칸에 적힌 글씨가 **유성 매직**이라 지울 수가 없다(→ 09번에서 연필로 바꿈).
- 🔵 **개발자용**: `contextControl`은 mode에 따라 조건부로 렌더링되는 JSX다. `<input value={props.title}>`처럼 value를 주면 React가 그 값을 강제하는 **controlled input**이 되는데, `onChange`로 값을 바꿀 길이 없으니 입력이 막힌다. React도 콘솔에 경고를 띄운다.

## 📥 시작 코드 (= 07 정답 + TODO)

```js
import './App.css';
import {useState} from 'react';

function Header(props){
  return <header>
    <h1><a href="/" onClick={(event)=>{
      event.preventDefault();
      props.onChangeMode();
    }}>{props.title}</a></h1>
  </header>
}
function Nav(props){
  const lis = []
  for(let i=0; i<props.topics.length; i++){
    let t = props.topics[i];
    lis.push(<li key={t.id}>
      <a id={t.id} href={'/read/'+t.id} onClick={event=>{
        event.preventDefault();
        props.onChangeMode(Number(event.target.id));
      }}>{t.title}</a>
    </li>)
  }
  return <nav>
    <ol>
      {lis}
    </ol>
  </nav>
}
function Article(props){
  return <article>
    <h2>{props.title}</h2>
    {props.body}
  </article>
}
function Create(props){
  return <article>
    <h2>Create</h2>
    <form onSubmit={event=>{
      event.preventDefault();
      const title = event.target.title.value;
      const body = event.target.body.value;
      props.onCreate(title, body);
    }}>
      <p><input type="text" name="title" placeholder="title"/></p>
      <p><textarea name="body" placeholder="body"></textarea></p>
      <p><input type="submit" value="Create"></input></p>
    </form>
  </article>
}
// TODO 4: Update 컴포넌트 만들기 (Create를 복사해서 시작)
//   - h2는 "Update", submit 버튼 value는 "Update"
//   - input에 value={props.title}, textarea에 value={props.body}
//   - onSubmit에서 props.onUpdate(title, body) 호출

function App() {
  const [mode, setMode] = useState('WELCOME');
  const [id, setId] = useState(null);
  const [nextId, setNextId] = useState(4);
  const [topics, setTopics] = useState([
    {id:1, title:'html', body:'html is ...'},
    {id:2, title:'css', body:'css is ...'},
    {id:3, title:'javascript', body:'javascript is ...'}
  ]);
  let content = null;
  // TODO 1: contextControl 변수 만들기 (기본값 null)
  if(mode === 'WELCOME'){
    content = <Article title="Welcome" body="Hello, WEB"></Article>
  } else if(mode === 'READ'){
    let title, body = null;
    for(let i=0; i<topics.length; i++){
      if(topics[i].id === id){
        title = topics[i].title;
        body = topics[i].body;
      }
    }
    content = <Article title={title} body={body}></Article>
    // TODO 2: contextControl에 Update 링크 넣기
    //   <><li><a href={'/update/'+id}>Update</a></li></>
    //   a의 onClick: preventDefault → setMode('UPDATE')
  } else if(mode === 'CREATE'){
    content = <Create onCreate={(_title, _body)=>{
      const newTopic = {id:nextId, title:_title, body:_body}
      const newTopics = [...topics]
      newTopics.push(newTopic);
      setTopics(newTopics);
      setMode('READ');
      setId(nextId);
      setNextId(nextId+1);
    }}></Create>
  }
  // TODO 5: else if(mode === 'UPDATE') 분기
  //   - READ와 같은 for 문으로 title, body 찾기
  //   - content = <Update title={title} body={body} onUpdate={(title, body)=>{ console.log(title, body); }}>
  return (
    <div>
      <Header title="WEB" onChangeMode={()=>{
        setMode('WELCOME');
      }}></Header>
      <Nav topics={topics} onChangeMode={(_id)=>{
        setMode('READ');
        setId(_id);
      }}></Nav>
      {content}
      <ul>
        <li><a href="/create" onClick={event=>{
          event.preventDefault();
          setMode('CREATE');
        }}>Create</a></li>
        {/* TODO 3: contextControl 출력 */}
      </ul>
    </div>
  );
}

export default App;
```

## ✍️ 할 일

1. `contextControl` 변수를 만들고, READ일 때만 Update 링크를 담는다.
2. `<ul>` 안에 `{contextControl}`을 출력한다.
3. Welcome 화면에서는 Update가 **안 보이고**, 글을 클릭하면 **보이는지** 확인한다.
4. `Update` 컴포넌트를 만들고 UPDATE 분기를 추가한다.
5. **관찰**: Update 폼에서 글자를 쳐 본다 → 안 쳐지는 것을 확인한다. F12 콘솔에서 React 경고(`You provided a \`value\` prop to a form field without an \`onChange\` handler...`)를 읽어 본다.
6. 수정하지 않은 채로 Update 버튼을 누르면 콘솔에 현재 값이 찍히는지 확인한다.

<details>

## 🧠 셀프체크 (코드 보지 말고 말로)

1. `contextControl`을 처음에 `null`로 두는 이유는? `{null}`은 화면에 어떻게 나오는가?
2. 왜 Update 폼에 글자가 안 쳐지는가? "React가 매번 무엇으로 되돌린다"로 설명해 보라.

<summary>답 보기</summary>

1. READ가 아닌 화면에서는 추가 메뉴가 없어야 하기 때문이다. JSX에서 `{null}`은 아무것도 그리지 않는다.
