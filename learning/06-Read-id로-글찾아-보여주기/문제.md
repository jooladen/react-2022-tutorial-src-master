# 06. Read — id로 글 찾아 보여주기

> MECE: **B1 Read**

## 🎯 이 단계가 끝나면

**화면**
```
html 클릭        → html / html is ...
css 클릭         → css / css is ...
javascript 클릭  → javascript / javascript is ...
WEB 클릭         → Welcome / Hello, WEB
```

**꽂을 한 문장**: **state 2개(mode, id)의 조합이 화면을 결정한다.** mode는 "어떤 화면", id는 "몇 번 글".

- 🟢 **초딩용**: 도서관에서 "소설 코너(mode)"만 알면 책을 못 찾는다. "몇 번 책(id)"까지 알아야 꺼내 줄 수 있다.
- 🔵 **개발자용**: 화면 = f(state). 렌더링마다 `mode`와 `id`를 보고 `topics`에서 데이터를 찾아 `Article`에 props로 넘긴다. 찾은 결과(title, body)는 state가 아니라 **state에서 계산되는 값**이다.

## 📥 시작 코드 (= 05 정답 + TODO)

```js
import './App.css';
import {useState} from 'react';

function Header(props){
  return <header>
    <h1><a href="/" onClick={(event)=>{
      event.preventDefault();
      props.onChangeMode();
    }}>{props.title}</a></h1>
  </header>
}
function Nav(props){
  const lis = []
  for(let i=0; i<props.topics.length; i++){
    let t = props.topics[i];
    lis.push(<li key={t.id}>
      <a id={t.id} href={'/read/'+t.id} onClick={event=>{
        event.preventDefault();
        props.onChangeMode(Number(event.target.id));
      }}>{t.title}</a>
    </li>)
  }
  return <nav>
    <ol>
      {lis}
    </ol>
  </nav>
}
function Article(props){
  return <article>
    <h2>{props.title}</h2>
    {props.body}
  </article>
}
function App() {
  const [mode, setMode] = useState('WELCOME');
  // TODO 1: id state 만들기 (초기값 null)
  const topics = [
    {id:1, title:'html', body:'html is ...'},
    {id:2, title:'css', body:'css is ...'},
    {id:3, title:'javascript', body:'javascript is ...'}
  ]
  let content = null;
  if(mode === 'WELCOME'){
    content = <Article title="Welcome" body="Hello, WEB"></Article>
  } else if(mode === 'READ'){
    // TODO 3: for 문으로 topics에서 id가 같은 글을 찾아 title, body에 담기
    content = <Article title="Read" body="Hello, Read"></Article>
    // TODO 4: 찾은 title, body를 Article에 넘기기
  }
  return (
    <div>
      <Header title="WEB" onChangeMode={()=>{
        setMode('WELCOME');
      }}></Header>
      <Nav topics={topics} onChangeMode={(id)=>{
        setMode('READ');
        // TODO 2: 클릭한 글의 id를 state에 저장 (매개변수 이름 주의 → 힌트 2)
      }}></Nav>
      {content}
    </div>
  );
}

export default App;
```

## ✍️ 할 일

1. `const [id, setId] = useState(null);`을 만든다.
2. Nav의 `onChangeMode`에서 `setId(...)`를 부른다.
3. READ 분기에서 `for` 문으로 `topics[i].id === id`인 글을 찾아 `title`, `body`에 담는다.
4. 찾은 값을 `<Article title={title} body={body}>`로 넘긴다.
5. **실험**: 04번에서 넣은 `Number(...)`를 잠시 빼고 html을 클릭해 본다 → 제목과 본문이 비는 걸 확인한다. 왜 그런지 말로 설명해 본 뒤 원래대로 되돌린다.

<details>
<summary>💡 힌트 2 — 매개변수 이름이 id면 생기는 문제</summary>

`onChangeMode={(id)=>{ setId(id); }}`도 동작은 한다. 하지만 바깥에 이미 state `id`가 있어서, 함수 안의 `id`가 어느 쪽인지 헷갈린다(shadowing). 강의자는 매개변수 이름을 `_id`로 바꿔 구분했다.

## 🔧 실무 버전

- 찾기는 `const topic = topics.find(t => t.id === id);` 한 줄로 쓴다.
- ⚠️ 강의 코드의 `let title, body = null;`은 `body`만 `null`이고 `title`은 `undefined`다. 쉼표로 선언하면 `= null`은 마지막 변수에만 붙는다. 이 코드에서는 결과가 같아서 문제가 안 드러날 뿐이다.

## 🧠 셀프체크 (코드 보지 말고 말로)

1. `title`, `body`는 왜 state로 만들지 않았을까?
2. 실험 5에서 `Number`를 빼면 왜 글이 안 나오는가?
3. 이제 **글을 추가**하고 싶다. `topics`가 지금처럼 `const` 일반 배열이면 추가한 글이 화면에 나올까? → **07번의 출발점**

<details>
<summary>답 보기</summary>

1. `topics`와 `id`만 있으면 언제든 계산해 낼 수 있는 값이기 때문이다. 계산 가능한 값까지 state로 만들면 두 값이 서로 어긋날 위험만 생긴다.
2. `event.target.id`는 문자열 `"1"`이고 `topics`의 id는 숫자 `1`이다. `===`는 타입까지 비교하므로 `"1" === 1`은 false가 되어 아무 글도 못 찾는다.
3. 안 나온다. 일반 배열에 push해도 React는 다시 그리지 않는다. 게다가 App이 다시 실행될 때마다 `const topics = [...]`가 처음 3개로 초기화된다. 그래서 `topics`도 state로 바꿔야 한다.
</details>
